# DotaZ — Product Brief

## Название и идея
**DotaZ** — веб-сайт для анализа матчей Dota 2 и повышения игрового мастерства. Игрок вводит ID матча и получает достоверную статистику, понятные наблюдения и рекомендации там, где доступны подтверждающие данные.

## Аудитория и задача
Игроки разных уровней, которые хотят разбирать матчи, видеть сильные и слабые стороны и ориентироваться в характеристиках героев. Главная пользовательская задача — понять, **что подтверждают данные матча**, а не получить необоснованную оценку.

## Основной сценарий
1. Зарегистрироваться, подтвердить email и войти.
2. Ввести ID матча на главной странице.
3. Открыть отчёт о матче: длительность, победитель, сведения о десяти участниках.
4. Выбрать игрока, посмотреть доступную статистику и наблюдения. По линии показывать данные 00:00–10:00, если доступны поминутные ряды/события.
5. Прочитать ограничения анализа. При повторном открытии использовать сохранённый отчёт.
6. Найти отчёт в личной истории. Выбрать язык: русский или английский.

## Функции MVP
- Регистрация и авторизация через Supabase Auth; подтверждение email (при соответствующей настройке проекта).
- Валидация ID матча и загрузка данных OpenDota.
- Сводка матча, статистика десяти игроков, выбор участника.
- Наблюдения на основе реальных показателей; частичный отчёт при нехватке данных.
- Анализ первых десяти минут **без оценочных выводов**, пока не подтверждены нормы героя/роли.
- История: один отчёт на `(user_id, match_id)`, только для владельца.
- Локализация RU/EN; понятные состояния загрузки и ошибок.

## Критерии качества
- Система не выдаёт отсутствие данных за ноль и не ставит необоснованные оценки.
- История защищена RLS; нельзя прочитать отчёт другого пользователя.
- Повторный или конкурентный анализ не создаёт дубликаты.
- 404, 403, 429 и 5xx внешнего API различаются.
- В отчёте присутствуют источник, дата получения и версия правил.

## Источники и ограничения
- Базовый источник: OpenDota `GET /api/matches/{match_id}`.
- В исходных материалах для матча `9007760151` подтверждено получение ряда поминутных данных после обработки реплея; их наличие для других матчей не гарантировано.
- OpenDota Benchmarks по `hero_id` и `role` подходят для сравнений **за матч в целом**; использовать их как нормы стадии линии нельзя.
- Мета, ролевая нормализация за первые десять минут, доказательное определение ошибок и анализ загружаемых реплеев требуют отдельного исследования и не считаются готовыми функциями MVP.

## Хранение
Supabase PostgreSQL; отчёт содержит общие данные матча и разделы всех десяти игроков. Уникальность: пара ID аккаунта и ID матча. История приватная.

## Проверочные матчи из исходного брифа
- `9035016192` — подпись «шторм» (непроверенная заметка исходного документа).
- `9007760151` — подпись «лион» (непроверенная заметка исходного документа, для матча ранее проверены расширенные данные).

## Не входит в первую версию
Загрузка собственных реплеев, платные подписки, реклама. Доказательные оценки линии и актуальная мета включаются только после подтверждения источников/методики.
