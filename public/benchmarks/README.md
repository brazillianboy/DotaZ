# Каталог нормативов (Task 16)

Здесь приложение ищет снапшот нормативов первых 15 минут:

```
public/benchmarks/benchmarks-7.41.json
```

**В репозитории этого файла нет** — он исключён из Git (`.gitignore`), потому что
права на публичное распространение производных данных OpenDota/Valve не подтверждены.

## Поведение без файла

Приложение собирается и работает без снапшота: запрос получает `404`, загрузчик
возвращает `null`, и на странице матча показывается состояние
«Нормативы недоступны: снапшот не загружен или не прошёл проверку».
Никакие статистические значения при этом не подставляются.

## Как включить нормативы локально

```powershell
# из корня проекта (нужен сетевой доступ к OpenDota Explorer)
node scripts/build-benchmarks.mjs --patch=7.41
Move-Item src/data/benchmarks-7.41.json public/benchmarks/benchmarks-7.41.json
```

Скрипт создаёт файл в `src/data/`; его нужно переместить в `public/benchmarks/`.
Альтернатива: сразу указать целевой каталог вручную после генерации.

## Как включить нормативы в публичном деплое

Только после того, как владелец подтвердит условия использования данных
(см. README, раздел «Нормативы первых 15 минут»):

1. сгенерировать снапшот на доверенной машине;
2. включить файл в артефакт развёртывания (не в Git), либо загрузить его в
   хранилище, доступное приложению по тому же пути `/benchmarks/…`;
3. проверить, что приложение показывает нормативы и атрибуцию OpenDota.

Удаление файла возвращает приложение в безопасное состояние «нет нормативов».
