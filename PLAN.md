# DotaZ: implementation plan

## Цель
MVP DotaZ (Tasks 1–13) завершён. Tasks 14–15 также реализованы и закоммичены. По сообщениям владельца Tasks 16–17 завершены; Task 18 технически реализован и проходит финальную ручную приёмку. Дальнейшее развитие согласовано до Task 23: аналитика и сравнения (16–20), финальный UI/UX (21), интерактивные графики матча (22), проверка безопасности, оптимизация и публикация (23). Этот файл — план, а не доказательство выполнения будущих задач.

## Порядок работы
**Задача ChatGPT → промпт для Cline → выполнение в VS Code → локальная проверка → commit → push.**

Правила:
1. Выполнять **строго по одной задаче** в порядке ниже. Следующую начинать только после проверки и фиксации предыдущей.
2. Перед задачей ChatGPT формирует для Cline конкретный промпт: файлы, ограничения, критерии приёмки, команды проверки. Ученик передаёт промпт в Cline, а не проектирует его самостоятельно.
3. Cline сначала изучает существующий код и не заменяет рабочие решения без причины. Не добавляет функциональность будущих задач.
4. После выполнения Cline сообщает изменённые файлы, результаты тестов и обнаруженные ограничения. Ученик лично проверяет сценарий в браузере и терминале.
5. При провале проверки исправить **в рамках текущей задачи**, повторить проверку; лишь затем выполнить `git add`, `git commit`, `git push`.
6. В Git не передавать `.env`, API-токены, ключи Supabase service_role, пароли, логи с секретами. Не использовать service_role в браузере.
7. Статус каждой задачи: `planned` → `in_progress` → `verified` → `done` (`blocked` — если не выполнена зависимость). `done` допустим только после успешного push.
8. После каждой завершённой задачи обновлять `PLAN.md`: статус, commit hash, что проверено. Само обновление включать в коммит задачи.
9. Подтверждённый стек по последнему отчёту проверки после Task 15: React, TypeScript, Vite, React Router, Supabase Auth/PostgreSQL/RLS, OpenDota, Vitest. Перед каждой задачей сверять с фактическим кодом.
10. Все промпты Cline составлять строго на английском; финальные отчёты Cline требовать полностью на русском. После каждого отчёта ChatGPT задаёт владельцу конкретные вопросы о желаемых изменениях. Git commit/push/deploy выполняет только владелец после проверки и отдельного разрешения.
